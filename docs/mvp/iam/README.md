# MVP IAM Docs

Use this folder for authentication, account, sign-up, login, and profile slice
documents.

## Folder Map

- `core/`: IAM-00 through IAM-06 and the authentication/accounts
  implementation plan.
- `login/`: login/session UX and backend login bridge slices.
- `signup/`: sign-up and external identity-provider slices.
- `user-profile/`: marketplace account, profile, avatar, and public identity
  label slices.

When adding a new IAM slice, place it in the matching subfolder and update
`docs/mvp/development-roadmap.md`.
