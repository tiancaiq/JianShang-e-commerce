# Create an account and manage your profile

## Common questions

- How do I create an account or sign in?
- How do I change my display name or phone?
- How do I upload an avatar?
- Can I change my email or password here?

## Who this applies to

Anyone who wants to save listings, message sellers, sell items, report content, use support, or use enabled business purchase tools.

## Prerequisites

None for account creation. Profile editing requires a signed-in session.

## Pages

- [Sign in or register](/login?client=marketplace)
- [Account dashboard](/account)
- [Profile](/account/profile)

## Create an account or sign in

1. Select **Login** in the marketplace header.
2. Choose **Create account** or **Sign in**.
3. For a new account, enter **Display name**, **Email**, and **Password**, then select **Create account**.
4. For an existing account, enter **Email** and **Password**, then select **Sign in**.
5. Use the account chip in the header to open **Account**.
6. Use **Logout** when you want to end the session.

## Update profile details

1. Open **Account**, then **Account details**, or go to `/account/profile`.
2. Change **Display name** or **Phone**.
3. Select **Save**. Select **Reset** to reload the last saved values.

## Manage an avatar

1. Under **Avatar image**, select **Choose image**.
2. Choose a PNG, JPEG, or WebP image no larger than 5 MB.
3. Select **Upload**.
4. To remove the current avatar, select **Remove**.

## Availability and safety limits

- **Email** is displayed but disabled on the profile form. There is no customer-facing email-change control.
- There is no password-change or password-reset page in the current frontend.
- Credentials are verified through the authentication gateway. Do not share a password in listings, chat, reports, or support requests.
- Optional dashboard links such as **Addresses**, **Your orders**, and **Notifications** appear only in environments where those features are enabled.
