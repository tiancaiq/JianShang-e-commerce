# Report a listing or business and appeal an eligible restriction

## Common questions

- How do I report a suspicious listing or business?
- What happens after I submit a report?
- Can I track my reports?
- How do I appeal an account, business, or listing restriction?

## Who this applies to

- Any signed-in user reporting a public listing or public business profile.
- An affected user or business/listing owner when an enforcement notice is marked appeal-eligible.

## Prerequisites

You must sign in. Reports should contain factual context and must not include secrets, payment credentials, or unnecessary private information.

## Pages

- [Listing report control](/listings/{listingId})
- [Business report control](/stores/{storeSlug})
- [Appeals](/account/appeals)

## Report a listing or business

1. Open the relevant public listing or store profile.
2. Select **Report listing** or **Report business**.
3. Under **What best describes the concern?**, choose the closest reason.
4. Add an **Explanation**. It is required when the reason is **Other**.
5. Select **Submit report**.
6. Save the displayed support reference if you may need to discuss the report with support.
7. Select **Done**.

## Appeal an eligible restriction

1. Open **Account**, then **Appeals**.
2. Under **Enforcement notices**, find the affected action.
3. If shown, select **Appeal this action**.
4. Under **Request a review**, choose a **Reason**.
5. Add an **Explanation**. It is required when the reason is **Other**.
6. Select **Submit appeal**.
7. Follow the status and any safe outcome summary under **Submitted appeals**.

## Availability and safety limits

- A report is an allegation for human review. Submission does not automatically remove content, restrict an account, issue a refund, or settle a dispute.
- The current customer UI does not provide a report-history page. Keep the support reference shown after submission.
- Only public listings and business profiles currently expose report buttons. There is no public user-profile report button in the current UI.
- Only eligible enforcement actions show **Appeal this action**. Submitting an appeal does not pause the restriction.
- Reports, support requests, order disputes, and appeals are different workflows. Use the control attached to the issue you need reviewed.
