# MSB Marketplace Help

This knowledge base explains the customer-facing workflows that exist in the current application. Articles use stable IDs so Marketplace Agent retrieval and citations do not depend on filenames or headings. Only files with public article front matter are eligible for the Agent corpus; internal coverage notes and this index are excluded.

Some commerce and AI workflows are available only in explicitly enabled demo environments. Each article states its availability. If a named link or button is not shown in the application, that workflow is not enabled in the current environment.

## Important purchase distinction

- Individual listings do not use the cart, checkout, platform payment, or orders. Buyers and sellers use messages and arrange payment and delivery themselves.
- Business listings can use the cart where it is enabled. Checkout, payment, orders, delivery, returns, and refunds in the current project are local-demo workflows only; they do not move real money.
